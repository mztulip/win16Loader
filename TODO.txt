ETAP 7 - INT 3F DLL thunk: przelaczanie DS przy wywolaniach DLL   [DONE]
--------------------------------------------------------------------------
Cel: poprawne przelaczanie DS=DGROUP przy kazym wywolaniu funkcji DLL.
Mechanizm:
  - Kazdy eksport DLL ma 5-bajtowy thunk: CD 3F, dll_idx, off_lo, off_hi
  - INT 3F handler: czyta thunk, patchuje IRET frame (CS=DLL_CODE, IP=func),
    ustawia DS=SEL_DLL_DATA, IRET do funkcji DLL
  - int3f_trampoline: po powrocie z DLL przywraca DS callera
[x] loader.c: emit_thunk, g_thunk_phys/size, IDT alokacja + wpis 0x3F
[x] pm_call.asm: SEL_THUNK (0x88), int3f_handler, int3f_trampoline
[x] Weryfikacja: DS przelaczany poprawnie, 3x OutputDebugString dziala

ETAP 10 - Pelna aplikacja Win16 + pełnoekranowy TextOut           [TODO]
--------------------------------------------------------------------------
Cel: "Hello, Win16!" widoczne w dowolnym miejscu ekranu graficznego 640x480.
Problem do rozwiazania: TextOut w GDI.EXE jest ograniczony do y<20 (pierwsze
64KB LFB) bo selektor jest 16-bitowy (SEL_VESA ma D/B=1 ale dostep z 16-bit
kodu uzywa 16-bit offsetu, max 65535 < 640*480*3=921600).

Rozwiazanie: TextOut uzywa address-size prefix (0x67) do 32-bit offset w
16-bit PM. W Watcom przez #pragma aux inline asm:
  mov ax, SEL_VESA
  mov es, ax
  db 0x67 ; address size prefix -> nastepna instrukcja uzywa 32-bit offsetu
  mov [es:edi], al   ; zapis przez 32-bit offset

MAPA GDT (STEP9c+)
-------------------
0x00  null
0x08  SEL_CODE32   flat 32-bit code (base=0, limit=4GB) - PM entry
0x10  SEL_DATA32   flat 32-bit data (base=0, limit=4GB) - font ROM, stos
0x18  SEL_DATASEG  loader DGROUP (base=g_cs_phys, limit=64KB)
0x20  SEL_CODE16   16-bit code (base=g_cs_phys) - powrot do RM, int3f
0x28  SEL_DATA16   16-bit data (base=g_cs_phys) - powrot do RM
0x30  SEL_APP_CODE 16-bit code apki (base=g_app_phys)
0x38  SEL_VGA      VGA text buffer (base=0xB8000, limit=0x09FF)
0x40  SEL_APP_DATA 16-bit data apki (base=g_app_data_phys)
0x48  SEL_DLL_CODE(0) = KERNEL code
0x50  SEL_DLL_DATA(0) = KERNEL data (DGROUP)
0x58  SEL_DLL_CODE(1) = USER code
0x60  SEL_DLL_DATA(1) = USER data (DGROUP)
0x68  SEL_DLL_CODE(2) = GDI code
0x70  SEL_DLL_DATA(2) = GDI data (DGROUP)
0x78  SEL_DLL_CODE(3) = (wolny slot)
0x80  SEL_DLL_DATA(3) = (wolny slot)
0x88  SEL_THUNK    thunki INT 3F (base=g_thunk_phys, 16-bit code)
0x90  SEL_VESA     LFB VESA (base=g_lfb_phys, 32-bit data, limit=1MB)
0x98  SEL_FONT     BIOS font ROM (base=g_font_phys, 16-bit data, limit=4KB)
